# Проверки

Установите Python 3.14.2 или новее и запустите из корня репозитория:

```sh
./scripts/check
```

Первый запуск создаёт `.venv` и устанавливает dev-зависимости. Для явного обновления окружения используйте `./scripts/bootstrap`. Тестовый harness `0.13.367` соответствует Home Assistant `2026.9.4`, версии в поддерживаемой серии `2026.9.*`.

Команда запускает unit-тесты, тесты форм, действий и smoke с настоящими модулями Home Assistant и локальными ответами RCI, проверку синтаксиса, JSON, Ruff и diff. Ruff проверяет весь код на ошибки импорта и неопределённые имена; для новых тестов также проверяет порядок импортов и форматирование. Уже существующие замечания по стилю и одна неиспользуемая переменная в production-коде пока не входят в проверку. GitHub Actions дополнительно выполняет HACS Action и hassfest. Локальный прогон не подтверждает результат CI или работу на живом роутере/Home Assistant.

`./scripts/check` также требует 100% покрытия строк и ветвлений `config_flow.py` HA-тестами через coverage.py. Отчёт выводит пропущенные строки и переходы; исключений для production-кода формы нет. Полное покрытие всей интеграции не заявляется.

Состояние применимых правил Bronze и причины исключений перечислены в `custom_components/keenetic_control/quality_scale.yaml`. Custom integration не получает официальный Bronze от наличия этого файла.
